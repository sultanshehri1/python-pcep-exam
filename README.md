# python-pcep-exam

نموذج MVP لموقع اختبارات تفاعلية لامتحانات بايثون (PCEP / PCAP / PCPP). الملفات الموجودة في هذا الفرع هي نسخة مبسطة تعمل دون سيرفر.

كيفية التشغيل محلياً

1. افتح الملف `index.html` في المتصفح (افتحه مباشرة من المستودع بعد تنزيله أو عبر خدمة استضافة ملفات).
2. اختر المستوى وعدد الأسئلة ثم اضغط "ابدأ الاختبار".

معاينة مباشرة عبر RawGit/RawGithack

بعد رفع الملفات إلى الفرع `feature/interactive-exam` يمكنك معاينتها مؤقتاً عبر خدمة RawGithack (لا تعتبر استضافة دائمة):

`https://raw.githack.com/sultanshehri1/python-pcep-exam/feature/interactive-exam/index.html`

ما الذي يمكنك فعله تالياً

- إنشاء Pull Request للدمج إلى الفرع الافتراضي.
- إضافة المزيد من الأسئلة في `data/questions.json` أو واجهة إدارة لاحقاً.
- تفعيل GitHub Pages لنشر النسخة العامة.

ملاحظات

- النسخة الحالية لا تنفذ كود بايثون على الخادم لاعتبارات الأمان؛ أسئلة نوع `code_output` تُقَيَّم بالمطابقة النصية لمخرجات متوقعة.
- إذا تريد أن أفتح PR أو أعدل الملف لبنك أسئلة أكبر أخبرني وسأنفذ ذلك.
